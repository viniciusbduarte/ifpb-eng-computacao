## 1. Conjuntos

### 1.1 Definição
Um **conjunto** é uma coleção bem definida de objetos, chamados de **elementos** ou **membros**.

Os elementos podem ser:
- números;
- cadeias de caracteres (strings);
- funções;
- outros conjuntos.

**Exemplo:**
```
A = {2, 5, 7, 8}
```

---

### 1.2 Propriedades dos conjuntos
- Os elementos **não se repetem**.
- A ordem dos elementos **não importa**:
  ```
  {1, 2, 3} = {3, 2, 1}
  ```

---

### 1.3 Multiconjunto
Um **multiconjunto** é uma generalização de conjunto que permite repetição de elementos.

**Exemplo:**
```
M = {1, 1, 2, 3}
```

> Multiconjuntos são úteis em modelagens probabilísticas e contagem de ocorrências.

---

### 1.4 Relações entre conjuntos

#### Pertinência
- x pertence a A: `x ∈ A`
- x não pertence a A: `x ∉ A`

#### Subconjunto
- A ⊆ B → A é subconjunto de B.
- A ⊊ B → A é subconjunto próprio de B.

---

### 1.5 Cardinalidade (tipos de conjuntos)

- **Vazio:**  
  ```
  ∅ ou {}
  ```
- **Finito:**  
  ```
  {1, 2, 3}
  ```
- **Infinito:**  
  ```
  {1, 2, 3, ...}
  ```

A cardinalidade de um conjunto A é denotada por |A|.

---

### 1.6 Operações com conjuntos

#### União
Conjunto formado por todos os elementos de A ou B:
```
A ∪ B
```

#### Interseção
Conjunto formado pelos elementos comuns a A e B:
```
A ∩ B
```

#### Diferença
Elementos de A que não estão em B:
```
A − B
```

#### Complemento
Elementos que não pertencem a A, considerando um universo U:
```
Aᶜ = U − A
```

## 2. Sequências e Tuplas

### 2.1 Sequência
Uma **sequência** é uma lista ordenada de elementos.

**Propriedades:**
- A ordem importa:
  ```
  (1, 2, 3) ≠ (3, 2, 1)
  ```
- Pode haver repetição:
  ```
  (1, 2, 2)
  ```

> Diferença fundamental:
- Conjunto → não possui ordem.
- Sequência → possui ordem.

---

### 2.2 Tuplas (k-uplas)

Uma sequência com k elementos é chamada de **k-upla**:
- 2-upla: dupla  
- 3-upla: tripla  
- k-upla: sequência com k elementos  

---

### 2.3 Conjunto das partes (conjunto potência)

Dado um conjunto A, o conjunto das partes P(A) é o conjunto de todos os subconjuntos de A.

**Exemplo:**
```
A = {0, 1}
P(A) = {∅, {0}, {1}, {0, 1}}
```

---

### 2.4 Produto cartesiano

Dado dois conjuntos A e B:
```
A × B = {(a, b) | a ∈ A e b ∈ B}
```

**Exemplo:**
```
A = {1, 2}
B = {a, b}

A × B = {(1,a), (1,b), (2,a), (2,b)}
```

> O produto cartesiano combina todos os elementos de A com todos os de B em pares ordenados.

Produto cartesiano de k conjuntos:
```
A₁ × A₂ × ... × Aₖ
```

## 3. Funções

### 3.1 Definição formal
Uma **função** é uma relação que associa a cada elemento do domínio exatamente um elemento do contradomínio.

Notação:
```
f: D → C
```

Onde:
- D = domínio
- C = contradomínio

---

### 3.2 Conceitos importantes

- **Domínio:** conjunto de entradas.
- **Contradomínio:** conjunto de possíveis saídas.
- **Imagem:** conjunto de valores realmente gerados pela função.

---

### 3.3 Funções k-árias

Uma função com k argumentos é chamada de **k-ária**:
- Unária (k = 1)
- Binária (k = 2)
- k-ária (k qualquer)

**Exemplo:**
```
soma(a, b) → função binária
```

---

### 3.4 Notações de funções

- Infixa:
  ```
  a + b
  ```
- Prefixa:
  ```
  +(a, b)
  ```
- Pós-fixa (notação polonesa reversa):
  ```
  a b +
  ```

#### Por que usar notação pós-fixa?
- Elimina a necessidade de parênteses.
- Facilita a avaliação por computadores.
- Muito utilizada em pilhas (stacks) e compiladores.

---

## 4. Predicados e Relações

### 4.1 Predicado

Um **predicado** é uma função cujo contradomínio é:
```
VF = {Verdadeiro, Falso}
```

**Exemplo:**
```
P: N → VF
```

Ou seja, a função verifica uma propriedade sobre números naturais.

---

### 4.2 Relações

Uma relação é uma generalização de predicado definida sobre pares ou k-uplas.

- Relação binária: definida sobre pares (a, b).
- Exemplos:
  - igualdade (=)
  - maior que (>)
  - menor que (<)

---

### 4.3 Exemplo: Pedra, Papel e Tesoura (PPT)

Domínio: pares de jogadas.

Interpretação da tabela:
- Linha → jogada do jogador 1
- Coluna → jogada do jogador 2
- Resultado → verdadeiro ou falso (vitória ou não).

## 5. Alfabetos, Cadeias e Linguagens

### 5.1 Alfabeto

Um **alfabeto** é qualquer conjunto finito e não vazio de símbolos.

Representação:
```
Σ (sigma)
```

---

### 5.2 Símbolos
Os elementos do alfabeto são chamados de **símbolos**.

---

### 5.3 Cadeias (strings)

Uma **cadeia** é uma sequência finita de símbolos de um alfabeto Σ.

- Cadeia vazia:
  ```
  ε
  ```
- Reverso de uma cadeia:
  ```
  w = abc → wʳ = cba
  ```
- Subcadeia:
  Parte de uma cadeia.

---

### 5.4 Comprimento de uma cadeia
O tamanho de uma cadeia w é denotado por |w|.

**Exemplo:**
```
w = abc → |w| = 3
```

---

### 5.5 Ordenação lexicográfica
É a ordenação baseada na ordem do alfabeto, semelhante à ordem do dicionário.

---

### 5.6 Linguagens formais

Uma **linguagem formal** é um conjunto de cadeias sobre um alfabeto Σ.

```
L ⊆ Σ*
```

Onde Σ* representa o conjunto de todas as cadeias possíveis sobre Σ.
