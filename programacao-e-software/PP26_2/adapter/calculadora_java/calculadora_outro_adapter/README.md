# Calculadora_202321250008

Calculadora básica com as quatro operações básicas: adição, subtração, multiplicação e divisão com o tipo double.

## Detalhes da atividade

- Sistema Operacional: Pop!_OS 24.04 LTS
- Versão do Compilador: javac 25.0.3
- IDE Usada: [micro](https://micro-editor.github.io/) (Versão 2.0.13)
- Tipo da Biblioteca Criada: .jar

## Descrição dos Métodos

### Adição

```java
public double somar(double... numeros) {...}
```

Retorna a soma de N números.

### Subtração

```java
public double subtrair(double a, double b) {...}
```

Retorna a - b.

### Multiplicação

```java
public double multiplicar(double... fatores) {...}
```

Retorna o produto de N fatores.

### Divisão

```java
public double dividir(double dividendo, double divisor) {...}
```

Retorna a divisão real do dividendo pelo divisor.
